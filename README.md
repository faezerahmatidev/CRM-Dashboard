# CRM-Dashboard (Angular)

CRM dashboard — implementation from Figma, step by step, with **Angular** standalone + SCSS + Angular Router.

## Current step: Auth (Login & Register)

Routes:

- `/signup` — Sign Up — *Welcome to our CRM. Sign Up to getting started.*
- `/signin` — Sign In — *Welcome to our CRM. Sign In to see latest updates.*
- `/recover` — Recover — *Lost your password? Enter your details to recover.*
- `/details` — Company details step — *Company name / Employees / Business / Phone*

Design tokens from `figma/UI-kit` (Primary `#5E81F4`, Lato font).

## Run

```bash
npm install
npm start
```

Build:

```bash
npm run build
```
