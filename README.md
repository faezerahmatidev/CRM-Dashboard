# CRM-Dashboard (Angular)

CRM dashboard — implementation from Figma, step by step, with **Angular** standalone + SCSS + Angular Router.

## Auth (Login & Register)

- `/signup` — Sign Up
- `/signin` — Sign In
- `/recover` — Recover password
- `/details` — Company details step

## Dashboard (from `figma/Dashboard`)

- `/dashboard` — Sales, Latest Events, Income Breakdown, Income Details
- `/dashboard/overview` — KPIs, Orders chart, Planned Income, Latest sales
- `/dashboard/orders` — Sparkline KPIs, Orders table, Invoices table
- `/dashboard/messages` — Messages + empty state

Design tokens from `figma/UI-kit` (Primary `#5E81F4`, Lato font).

## Run

```bash
npm install
npm start
```

Build:

```bash
npm run build
```
